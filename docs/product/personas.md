# Target users & personas

**Status:** Accepted

## Initial focus

Ship for **Linux developers and technical power users** first. Expand to students, researchers, and knowledge workers once the core select→act loop is proven.

---

## Developers (primary)

**Goals:** Fix errors faster, understand unfamiliar output, capture technical notes without leaving flow.

**Use cases:**

- Understand error messages
- Search Stack Overflow / GitHub / web
- Explain code
- Convert screenshots into HTML/CSS (v2)
- Extract API information
- Save useful technical information
- Calculate technical values

**Success signal:** Uses marquee on terminal/IDE errors multiple times per day.

---

## Students

**Goals:** Solve problems and capture study material from PDFs, slides, and browsers.

**Use cases:**

- Solve mathematical problems
- Explain textbook content
- Search concepts
- Summarize selected content
- Save study notes

**Success signal:** Calculator + Save Note become habitual during study sessions.

---

## Researchers

**Goals:** Capture and organize information from papers and sites with minimal friction.

**Use cases:**

- Capture information from papers/websites
- Search selected concepts
- Summarize information
- Save research notes
- Organize references

**Success signal:** Structured notes with source + screenshot replace ad-hoc screenshots.

---

## Knowledge workers

**Goals:** Capture meeting/document content; rewrite, search, and analyze without tool juggling.

**Use cases:**

- Capture information from meetings/documents
- Rewrite text
- Search unfamiliar concepts
- Save important information
- Analyze charts and tables

**Success signal:** Ask AI + Notes used weekly on desktop content outside coding tools.

---

## Anti-personas (MVP)

- Users who need full mobile or Windows/macOS support first
- Teams needing shared note sync and collaboration
- Users unwilling to provide any AI API key / cloud processing (local-only path is v3)
