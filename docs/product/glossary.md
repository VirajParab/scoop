# Glossary

| Term | Meaning |
|------|---------|
| **Scoop** | Product name (working and full name) |
| **Library** | Local store of arranged screenshots & copied text, searchable anytime |
| **Collection** | User folder/group inside the Library (default: Inbox) |
| **Marquee** | Drag-rectangle screen selection |
| **Intent Engine** | Ranks contextual actions from OCR + classification |
| **Smart Note** | AI-structured note draft (editable before save) |
| **Provider** | Pluggable AI or search backend |
| **Content type** | Classification label (CODE, MATH, …) |
| **P0** | Must-have for MVP |
