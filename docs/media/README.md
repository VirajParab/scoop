# Media assets

Drop demo media here so the root [README](../../README.md) renders on GitHub.

| File | Suggested content |
|------|-------------------|
| `demo.mp4` or GitHub video upload | 20–40s product loop |
| `screenshot-home.png` | Brand home / Start selection |
| `screenshot-toolbar.png` | Selection result panel (image + OCR + actions) |
| `screenshot-editor.png` | Paint editor with annotations |
| `screenshot-library.png` | Library item with tags + linked note |

**Tips**
- Capture at 1280–1600px wide, dark Scoop UI looks best with a thin window chrome
- Prefer lossless PNG for UI shots
- Keep filenames exactly as listed so README links work
